# CS50W Commerce Project

An auction site built as part of Harvard's CS50's Web Programming with Python and JavaScript (CS50W) course.

This project was made using Django, written in the languages:

Python

HTML

CSS

# Features

Once logged in users can create a listing, where they can add a title, description, starting bid, an image and a category

Index page, which shows all currently active listings

Listings page, where you can see the listings details, bid on an item, and comment on the listing

The listings owner is able to close a listing, which will result in the page displaying who won the bid

Users can add a listing to a watchlist, which will result in that bid appearing in their watchlist page.

Users can also sort listings by categories

Admin users can also access Django Admins Interface to change, view, or delete any listings, bids, or comments
